# Proyecto entorno servidor

## Instrucciones de instalacion.
Para descargar este archivo tenemos que clonarlo y seguir los siguientes pasos

1. hacer una copia del fichero env.example y renombrarlo a .env
2. Introducir el nombre de usuario, uid, git, en las variables.
3. Arrancar docker.
4. Ejecurar con voton derecho opcion ehecutar sobre el docker compose.yaml
5. Contenido a seguir usando en la carpeta herramientas.
